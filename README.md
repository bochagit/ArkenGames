# 🎮 ArkenGames

ArkenGames es un sitio web desarrollado completamente con **HTML, CSS y Vanilla JavaScript**. El objetivo del proyecto es ofrecer una experiencia rápida, responsiva y sencilla, enfocada en la presentación de los productos que ofrece la editorial.

🌐 **Sitio online:** https://arkengames.com.ar/  

---

## 🚀 Características principales

- **Desarrollo desde cero** utilizando únicamente tecnologías base.
- **Totalmente responsive**, adaptable a móviles, tablets y escritorio.
- **Interfaz ligera**, rápida y de carga optimizada.
- **Arquitectura simple**, ideal para comprender y modificar.
- **Hosting en DonWeb**, con dominio configurado desde **NIC.ar** e integración de **Cloudflare**.

---

## 🛠️ Tecnologías utilizadas

- **HTML5**
- **CSS3**
- **JavaScript (ES6+)**
- **Git / GitHub**
- **Cloudflare** (DNS y performance)
- **DonWeb** (hosting)
- **NIC.ar** (dominio)

## 💡 Objetivo del proyecto

El propósito de ArkenGames es practicar y reforzar conceptos fundamentales de:

- Desarrollo web sin frameworks  
- Manejo de archivos estáticos  
- Organización de un proyecto real  
- Deploy y configuración de infraestructura web  
- Optimización básica y responsive design
